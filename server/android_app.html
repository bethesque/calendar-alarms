How to install

  1. Tap the download button above. If your browser warns that the file might be harmful, choose Download anyway.
  2. Open the Files app on your phone (it may be called Files by Google or My Files).
  3. Go to the Downloads folder and tap $apk_name.
  4. If prompted that installing unknown apps is not allowed, tap Settings, turn on Allow from this source for the Files app, then go back.
  5. Tap Install. If Google Play Protect warns about an unrecognised app, tap More details then Install anyway.
  6. Tap Open to start the app.

Don't open the file from the browser's download notification, as that would give the browser permission to install apps.

Updating

To update, download the latest version from this page and install it from the Files app in the same way. It will install over the top of the existing app and keep your settings.
